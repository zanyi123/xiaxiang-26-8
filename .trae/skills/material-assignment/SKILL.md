# 素材智能分配技能

## 核心规则

### 1. 编号格式规则
- **格式**：`类型-模块编号-序号`
- **类型前缀**：
  - `VID` = 视频
  - `IMG` = 图片
  - `MDL` = 3D模型
  - `AUD` = 音频
- **模块编号对照表**：

| 模块名称 | 编号 | 说明 |
|---------|------|------|
| 云游侨乡-建筑总览 | 01 | 建筑列表页、建筑详情页使用 |
| 云游侨乡-地点 | 02 | 地图导航页地点详情使用 |
| 侨乡故事 | 03 | 故事列表和详情页 |
| 建筑解剖 | 05 | 碉楼部位分解页 |
| 知识库 | 06 | 知识条目详情 |
| 民俗文化 | 07 | 民俗内容展示 |
| 实践日志 | 08 | 实践记录展示 |
| 视频展播 | 09 | 独立视频展播页面 |
| 团队成员 | 10 | 团队成员头像 |
| 老照片对比 | 11 | 新老照片对比 |
| 侨批文化 | 12 | 侨批相关展示 |
| 方言学习 | 13 | 方言音频 |
| 虚拟盖章 | 14 | 盖章互动图片 |
| 项目成果 | 16 | 成果展示素材 |

### 2. 分配原则
- **不跨模块重复使用素材**：每个素材只分配到一个模块
- **先查验原模块需求，再分配新素材**：
  1. 读取 `素材上传总清单.xlsx` 查看各模块待传素材
  2. 对比新上传的素材清单
  3. 按内容相关性智能分配到对应模块
- **内容相关性优先**：
  - 建筑特写视频 → 建筑模块（VID-01）
  - 地点航拍视频 → 对应地点模块（VID-02）
  - 宣传、总结类视频 → 视频展播模块（VID-09）
  - 封面图、对比图 → 对应图片模块
  - 3D模型 → 建筑/地点模块

### 5. 常见场景处理

#### 场景1：新上传视频清单
1. 读取视频清单
2. 分析视频内容（建筑特写/航拍/宣传）
3. 分配到对应模块
4. 更新配置

#### 场景2：新上传图片清单
1. 读取图片清单
2. 分析图片类型（封面/对比/内容图）
3. 分配到对应模块
4. 更新配置

#### 场景3：新上传模型清单
1. 读取模型清单
2. 分析模型类型（建筑/地点）
3. 分配到对应模块
4. 更新配置

### 6. 注意事项

- **不要修改已有分配**：除非用户明确要求重新分配
- **保持编号连续**：同一模块内的序号从01开始连续
- **记录分配历史**：所有分配操作都要记录到 `素材分配记录.json`
- **验证完整性**：分配完成后验证所有素材都已分配
- **禁止跨模块重复**：一个素材只能属于一个模块

### 7. 触发条件

当用户执行以下操作时，应调用此技能：
- 上传视频/图片/模型清单
- 要求分配素材到对应模块
- 询问素材编号规则
- 需要查看当前素材分配情况
- 提到"素材分配"、"素材归类"、"编号"等关键词
