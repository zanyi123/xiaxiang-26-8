## 第二部分：网站导览二级专栏 · 后台动态工作流分析

### 工作流分类

按内容性质，所有专栏归为 3 类：

| 类型 | 说明 | 适用专栏 |
|------|------|----------|
| **A 类** | 纯文字单元型（文字 + 可选素材） | 侨批文化、侨乡故事、知识库、方言学习、民俗文化、实践日志、视频展播、团队成员 |
| **B 类** | 地理/空间型（含坐标 + 多素材） | 云游侨乡、建筑解剖、老照片对比 |
| **C 类** | 固定结构型（暂不需动态增删） | 首页 Hero、项目成果（建筑列表）、我的侨乡人生、知识答题、虚拟盖章、关于我们 |

## 第三部分：实施计划

### 第一阶段：清除虚构数据（风险最低、见效最快）

1. 删除虚构文本：`stories[0].content`、`qiaopi[*].content/translation`、`knowledge[*].content`、`locations[*].history/audioText`、`team[*].bio`
2. 移除虚假日期：`stories[0].date`、`blogPosts[*].date`
3. 计数器归零：`stories[0].views`、`videos[*].views`、`archives[*].count`
4. 删除虚构成员：`team[1]`（张伟）
5. 修正 Hero 区统计：删除"100+ 年"、修正"6 栋"为"6 个地点"

### 第二阶段：搭建后台动态管理框架

1. 创建内容管理后台页面（`/admin/content`），按专栏分组
2. 实现统一 CRUD：每个 A/B 类模块的增删改查
3. 素材编号自动规划：新增单元时自动分配 Slot ID 并持久化到 yml
4. 同步更新前端：修改后前端页面立即反映

### 第三阶段：动态统计实现

1. 访问量计数：在 `StoryController.storyDetail()` 等接口增加访问计数（内存 Map + 定时落盘 yml）
2. 档案数量统计：`CosService` 增加 countByPrefix() 方法
3. 播放量计数：前端 video.play 事件上报
